## MODIFIED Requirements

### Requirement: Dependency-free Node tools
Copied tool code SHALL be plain `.mjs` (or `.json` data), with no npm dependencies, and SHALL run on Node 22.0.0 or newer. It SHALL be generated by this repository's build from the TypeScript source under `src/` and SHALL NOT be edited by hand. Tests for the tools SHALL live outside the skill folders.

#### Scenario: Node 22.0.0
- **WHEN** CI runs `node --test "tests/agent-harness/*.test.mjs"` on Node 22.0.0
- **THEN** every test passes

#### Scenario: No TypeScript reaches a target repo
- **WHEN** the files under `skills/agent-harness-hook-runtime/assets/` and `skills/agent-harness-verify-gate/assets/` are listed
- **THEN** none has the extension `.mts` or `.ts`

### Requirement: This repository is onboarded
This repository SHALL have both tools installed from its own skills, a `verify-gate.command` of `node scripts/verify.mts`, host configs for Claude Code and OpenCode, and CI steps running both tools' `check` and the harness tests on Node 22.

#### Scenario: CI check
- **WHEN** the validate workflow runs on a pull request
- **THEN** it runs `check` for `hook-runtime` and `verify-gate` and fails if either fails

#### Scenario: Verify command
- **WHEN** `.agents/harness.json` is read
- **THEN** `verify-gate.command` is `["node", "scripts/verify.mts"]`
